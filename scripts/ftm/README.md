# ftm — перебор ioctl зарядчика (тупиковый эксперимент)

Исследование 2026-10-22: планшет MTK (mt6370 + SGM41513) не заряжается от
USB-A-порта ПК, потому что драйвер классифицирует источник как «USB-порт ПК»
и выключает заряд. Мы пробовали достучаться до зарядчика через
`/dev/charger_ftm` и перебрали ~3300 кодов `_IO/_IOR/_IOW/_IOWR` по всем
буквам.

**Результат: эффекта нет.** Драйвер/железо всё равно уходят в ветку PE+ и
`CHG_EN=0`. Файлы оставлены как evidence, а не как рабочий инструмент.

- `ftm.go` — обёртка/хелпер;
- `sweep.go` — перебор кодов;
- `../ftm_ioctl.c` — то же на C.

Запускать на планшете с root, только если понимаете риск: это прямой доступ
к PMIC. Для обычного стрима не нужно.
